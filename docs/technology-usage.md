## Icons

Brand marks come from [Simple Icons](https://github.com/simple-icons/simple-icons) 16.38.0 (CC0) and [Devicon](https://github.com/devicons/devicon) v2.17.0 (MIT). Source URLs are recorded per technology in [the catalog](../assets/v3/technologies.json).

REST APIs, SQL, gRPC, Telegraf, TensorBoard, Pillow and Tkinter use descriptive concept symbols. PySide6 uses the Qt mark to identify its underlying framework. These symbols do not imply separate official product logos.

The SVG panels embed every icon, so viewing the profile does not depend on an icon service.

The language-percentage chart in the reference was not copied: code-byte shares describe repositories and are not skill ratings.
